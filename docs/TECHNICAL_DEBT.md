## Closed or downgraded from the cleanup register

- Process-local auth is an explicit supported topology with worker/serverless guards, atomic challenge consumption and adversarial session tests. A distributed store is conditional P2 rather than mandatory infrastructure.
- Independent wire/PDA/account/metadata/expiry/recovery vectors and marketplace baseline-aware recovery address the parity prerequisite. Consolidation itself is conditional.
- Dependency triage now covers all four application graphs, non-npm inventories and documented dated exceptions. Remaining deadlines are tracked above; advisory counts are not silently zeroed.
- Raw JSON transport capture was replaced by an internal validated snapshot engine with bounded concurrency, cancellation and history retained across reads within the process. No remaining capture-coupling task.
- Explicit profiles, origin/topology/policy validation and saved public build bindings replace silent hosted local defaults. Owner-provided hosting configuration remains an external gate.
- Current committed-checkout validation orchestrates SDK-first installs and serial browser builds. Twelve isolated packed-consumer checks test public package boundaries. A workspace/monorepo migration is unnecessary.
- Saturday compatibility now requires an explicit optional read-only path; absence is an intentional recorded skip. No unrelated repository checkout or modification is required.
- Fixed offers and old deployment claims are fixture/historical evidence. Strict profiles reject known fixtures; read-only identity tooling records actual artifact/authority relationships separately.
- Root Base `.env.example` and active web/example templates have separate scopes. Retaining the isolated fallback template is not a defect; retire only with evidence no external tooling depends on it.
